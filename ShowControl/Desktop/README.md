发送数据类型可选 String 文本或 HEX 原始字节。String 支持 UTF-8、ASCII、GBK（ANSI 936）和 Windows-1252，采用明确的代码页以保持跨平台一致。HEX 按填写的字节发送，不转换为文本。回执可按指定 String 编码完全匹配、包含匹配，或按 HEX 字节匹配。旧工程未指定编码时继续使用 UTF-8。IP 库可配置允许的回执源端口，留空允许该 IP 的任意源端口。

不同 IP 的请求并行执行，同一 IP 的 Cue 和软件健康查询共用队列。没有请求编号的协议按串行方式关联回执，超时或取消后为该 IP 保留一个原回执超时时长的隔离窗口，等待中的下一请求可随时停止。超出隔离窗口的迟到包或成功回执的延迟副本仍需协议中的请求编号才能彻底区分。已发出的 UDP 数据不能通过停止操作撤回。

日志逐包记录来源 IP、来源端口、本机接收地址、实际文本与 HEX，内容不匹配、未关联回传同样保留。节点看板显示最近回传及其时间，状态仍由独立的健康检测规则判断。现有看板导出包含最近回传字段，完整统计与导出界面将在后续阶段完善。

Windows x64 版在发布目录内双击 `SymphoCue.exe` 启动。请保留同目录的 `resources`、`locales` 和运行库文件。从关闭提示或托盘菜单选择「完全退出」会停止本次桌面实例的引擎和定时任务。

首次运行会使用同目录下已有的 `data/project.json`，或在当前工作区复用相邻 `ShowControl/data/project.json`。已使用旧桌面版默认用户数据目录的工作站会继续读取其中的工程。全新安装的数据默认放在应用的用户数据目录。也可用 `SHOWCONTROL_DATA_DIR` 或 `--project-directory` 指向已有工程。使用同一工程时，请先退出先前启动的桌面实例或独立服务。


定时任务可选周循环、指定日和节假日日期范围。同一播放组当天有可执行的已启用任务时，指定日优先于节假日，节假日优先于周循环。不同播放组独立判断。低优先级任务到点会在日志中显示跳过原因。手动 Go 和 Action Pad 仍可触发。

每条 Cue 可以为多个目标组分别配置指令、编码、端口和回执。各组可选择不等待或匹配自定义 UDP 回执，ICMP Ping 与失败策略仍是 Cue 设置。旧工程的回执规则保留，新建目标默认不等待回执。旧工程的定时任务默认每天运行。

IP 分组库可导入和导出 .xlsx 或 TXT。可先导出模板并按表头填写，Excel 读取第一个工作表，TXT 使用 UTF-8 制表符分隔。每行一个 IP 的 TXT 会导入「导入节点」分组。导入按分组 ID 或名称合并，同组同 IP 的节点会更新，验证通过后即时合并。执行日志按本机日期追加到数据目录的 `logs/YYYY-MM-DD.txt`，同日重启继续追加。日志面板可查看文件夹路径。管理员可在「日志设置」保存界面最大行数（1–2000，默认 300），也可用「清空列表」从空白列表开始查看新记录。每日 TXT 仍可在日志文件夹中查询。

在「列表设置」选择顺序播放一次或循环播放，并设置默认间隔。Cue 属性可为单条 Cue 覆盖等待时间，留空时使用列表间隔。点击「播放」立即启动首条 Cue，之后从每条 Cue 执行结束起计时。循环最后一条结束并等待后回到首条。「停止」会取消等待、重试和后续 Cue。定时任务和 Action Pad 也使用列表的播放设置。旧列表默认顺序播放一次，间隔为 0。

在「列表设置」给每个 Cue 列表指定播放组。不同组可以并行，同组触发新列表时先取消并等待上一个退出。定时任务遇到同组手动或 Action Pad 播放时跳过。同一分钟内同组多个定时任务只接收第一个。列表的「停止」只停止该列表。旧列表默认属于「默认」播放组。

项目树的每个 Cue 列表都有播放和停止。顶部「停止全部调度」取消所有播放组，Action Pad 的按钮动作也可以选择「停止全部调度」。拖动标题旁的 ⠿ 到另一面板可交换位置。将鼠标移到面板边线，边线高亮后拖动即可调整尺寸。也可以聚焦边线并按方向键调整。位置和尺寸自动保存，可从「工作台设置 → 恢复默认布局」复位。

在「工作台设置」中设置管理员密码和可选的操作员密码。操作员可以播放、停止和查看状态，工程、IP 库及布局由管理员配置。锁屏会撤销工作站控制权限，正在播放的列表和定时任务继续运行。配置过权限的工作站启动后需要解锁。桌面程序运行时会请求系统避免闲置休眠。

节点看板分别显示设备和软件状态。设备状态取决于 Ping。启用「Ping + UDP 软件回执」后，可设独立查询端口、UTF-8 指令和预期回执，刷新节点状态时检测。IP 库 Excel/TXT 的「健康模式」列使用 `ping` 或 `udp`，UDP 模式须填写「查询端口」「查询指令」「预期回执」。仅 Ping 时软件状态显示未配置，软件查询超时显示未确认。

「工作台设置 → UDP 网卡」列出本机网卡、IP 和就绪状态。勾选本项目要使用的网卡后，可以为多个目标网段分配网卡，例如把 `192.168.10.0/24` 交给以太网、`192.168.20.0/24` 交给另一张网卡。重叠规则优先选前缀最长的网段。未匹配的目标走显式设置的默认网卡，采用自动默认时按勾选顺序使用第一张网卡。没有勾选时使用系统路由。回环地址始终走本机。设置保存到工程，供新触发的播放和软件健康查询使用。某张固定网卡不可用时，该网卡的待发指令等待恢复，其他网卡仍可发送。Ping 使用系统路由。

节点看板支持 25、50、100 条每页。管理员可以保存 5–3600 秒的自动检测间隔，每轮完成后再计时，设置为 0 表示手动刷新。项目树按演出分页，可搜索演出、分组、Cue 列表和 Cue 名称。

## 调度与配置行为

同一 Cue 内，重叠目标组产生的相同 IP、目标端口和实际报文会合并发送，预览保留来源组。重复报文的回执或重试规则不一致时，配置校验会提示冲突。不同报文按原顺序发送。

自动重试须同时设置 Cue 的失败策略为重试，并在模板或目标组允许重复执行。旧工程缺少允许重试设置时，默认只发一次。Ping 检测独立记录为网络状态，回执判定使用 UDP 收发结果。

新 Cue 的目标端口默认继承模板或节点。添加目标组会复制上一组的回执和重试设置。已有显式覆盖可通过“恢复目标组继承”清除。属性面板显示当前生效值和来源。

“停止调度”和“停止全部调度”取消平台的后续发送、等待和重试。“停止现场”执行列表设置中绑定的现场停止流程，先等待本播放组旧任务退出，再单次执行该流程。该流程中的 UDP 内容由现场 LAS 工程实际命令填写。Action Pad 的播放按钮可附带停止调度或停止现场按钮。现场停止确认框显示目标组和可能受影响的运行流程，结果通过执行日志核对。两个流程共用节点时，控制分区用于提示影响范围。用 `*` 表示整节点，分区标签应与 LAS 工程核对。

播放和现场停止会核对页面显示的工程版本。版本更新后需刷新并重新确认。旧工程可保留冲突回执或缺端口的配置供修正，起播前预检会拦截对应的整个 CueList。

IP 库导入按字段更新已有节点。端口留空时保留原值，填写 `-` 才清空。定时记录损坏时，管理员可核对已保留的任务记录并确认恢复，自动调度从下一分钟开始。

单独编辑节点时可设置批量修改保护。一次批量覆盖保留原保护标记，取消保护在节点设置中明确操作。节点移出最后一个分组后保留在台账，可通过“删除未分组节点”移除。

## 构建桌面版

Windows x64 在工作区根目录执行以下命令，传入官方 Electron Windows x64 ZIP。脚本用 .NET 10 SDK 发布自包含引擎，再与 Electron 运行库组装。

```powershell
./ShowControl/Desktop/package-windows.ps1 -ElectronArchive ./electron-v45.2.3-win32-x64.zip -ResourceEditor ./rcedit-x64.exe
```

桌面入口也支持 macOS 和 Linux。打包时使用对应平台的 Electron 发行包，将本目录的 `main.cjs` 和 `package.json` 放在 Electron 的 `resources/app`，将对应 RID 的自包含 `dotnet publish` 输出放在 `resources/engine`。macOS 对应的目录在 `Electron.app/Contents/Resources`，本地分发按 macOS 要求进行签名。
