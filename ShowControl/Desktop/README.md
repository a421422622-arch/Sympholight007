# 灯控编排台桌面版

1.7.0 增加统一节点设置、批量字段修改与单独设置保护。IP 库可修改节点默认目标端口、自动或固定发送端口、独立接收端口，以及独立于网络 Ping 的 UDP 软件查询。模板可配置目标端口和回执规则，Cue 可为单个 IP 指定模板、端口和回执例外。「执行预览」按当前草稿显示逐 IP 的最终参数与来源。目标端口优先级为节点例外、Cue 目标组、模板、节点默认值。旧 Cue 的组别端口和回执设置保持原有语义，选择留空端口或「沿用命令模板」才启用继承。

固定发送端口与独立接收端口在此版本中用于配置和模拟预览，真实发送会明确阻止使用这些配置的列表，待统一收发引擎接入后启用。自动发送端口与跟随发送端口接收继续支持真实 UDP。节点库按 IP 统一设置，分组保留兼容字段，同一 IP 在所有组共享节点资料。首次读取旧工程时自动保存 `project.json.before-node-library.bak`，迁移结果在保存项目时写入工程。Excel/TXT 导入导出包含通信与健康查询字段。

Windows x64 版在发布目录内双击 `ShowControlDesktop.exe` 启动。请保留同目录的 `resources`、`locales` 和运行库文件。程序自带界面和灯控引擎，退出窗口会停止本次桌面实例的引擎和定时任务。

首次运行会使用同目录下已有的 `data/project.json`，或在当前工作区复用相邻 `ShowControl/data/project.json`。全新安装的数据默认放在应用的用户数据目录。也可用 `SHOWCONTROL_DATA_DIR` 指向已有工程所在目录。使用同一工程时，请先退出先前启动的独立服务。

默认使用模拟模式。沿用原来的环境变量 `SHOWCONTROL_LIVE=1` 启用真实 UDP。

定时任务可选周循环、指定日和节假日日期范围。当天有可执行的已启用节目任务时，指定日优先于节假日，节假日优先于周循环。低优先级任务到点会在日志中显示跳过原因。手动 Go 和 Action Pad 仍可触发。

每条 Cue 可以为多个目标组分别配置指令、编码、端口和回执。各组可选择不等待或匹配自定义 UDP 回执，ICMP Ping 与失败策略仍是 Cue 设置。旧工程的回执规则保留，新建目标默认不等待回执。旧工程的定时任务默认每天运行。

IP 分组库可导入和导出 .xlsx 或 TXT。可先导出模板并按表头填写，Excel 读取第一个工作表，TXT 使用 UTF-8 制表符分隔。每行一个 IP 的 TXT 会导入「导入节点」分组。导入按分组 ID 或名称合并，同组同 IP 的节点会更新，核对草稿后点击保存项目。执行日志按本机日期追加到数据目录的 `logs/YYYY-MM-DD.txt`，同日重启继续追加。日志面板可查看文件夹路径，窗口显示最近 300 条，磁盘日志不按 300 条截断。

在「列表设置」选择顺序播放一次或循环播放，并设置默认间隔。Cue 属性可为单条 Cue 覆盖等待时间，留空时使用列表间隔。点击「播放」立即启动首条 Cue，之后从每条 Cue 执行结束起计时。循环最后一条结束并等待后回到首条。「停止」会取消等待、重试和后续 Cue。定时任务和 Action Pad 也使用列表的播放设置。旧列表默认顺序播放一次，间隔为 0。

在「列表设置」给每个 Cue 列表指定播放组。不同组可以并行，同组触发新列表时先取消并等待上一个退出。定时任务遇到同组手动或 Action Pad 播放时跳过。同一分钟内同组多个定时任务只接收第一个。列表的「停止」只停止该列表。旧列表默认属于「默认」播放组。

项目树的每个 Cue 列表都有播放和停止。顶部「全部停止」取消所有播放组，Action Pad 的按钮动作也可以选择「全部停止」。拖动面板的 ⠿ 到另一面板可交换位置，拖动四边可调整单边尺寸，相邻面板的分隔边会同步调整两侧，右下角 ◢ 可同时调整宽高。聚焦手柄后也可用方向键调整。位置和尺寸自动保存，顶部可恢复默认。

在顶部「设置权限」设置管理员密码和可选的操作员密码。操作员可以播放、停止和查看状态，工程、IP 库及布局由管理员配置。锁屏会撤销工作站控制权限，正在播放的列表和定时任务继续运行。配置过权限的工作站启动后需要解锁。桌面程序运行时会请求系统避免闲置休眠，关闭程序会停止引擎。

节点看板分别显示设备和软件状态。设备状态取决于 Ping。启用「Ping + UDP 软件回执」后，可设独立查询端口、UTF-8 指令和预期回执，刷新节点状态时检测。IP 库 Excel/TXT 的「健康模式」列使用 `ping` 或 `udp`，UDP 模式须填写「查询端口」「查询指令」「预期回执」。仅 Ping 时软件状态显示未配置，软件查询超时显示未确认。

顶部「UDP 网卡」列出本机网卡、IP 和就绪状态。可为多个目标网段设置网卡，例如把 `192.168.10.0/24` 交给以太网、`192.168.20.0/24` 交给另一张网卡。重叠规则优先选前缀最长的网段，未匹配目标走所选默认网卡或系统路由。回环地址始终走本机。设置保存到工程，供新触发的播放和软件健康查询使用。某张固定网卡不可用时，该网卡的待发指令等待恢复，其他网卡仍可发送。Ping 使用系统路由。

节点看板支持 25、50、100 条每页。管理员可以保存 5–3600 秒的自动检测间隔，每轮完成后再计时，设置为 0 表示手动刷新。项目树按演出分页，可搜索演出、分组、Cue 列表和 Cue 名称。

## 构建桌面版

Windows x64 在工作区根目录执行以下命令，传入官方 Electron Windows x64 ZIP。脚本用 .NET 10 SDK 发布自包含引擎，再与 Electron 运行库组装。

```powershell
./ShowControl/Desktop/package-windows.ps1 -ElectronArchive ./electron-v45.2.3-win32-x64.zip
```

桌面入口也支持 macOS 和 Linux。打包时使用对应平台的 Electron 发行包，将本目录的 `main.cjs` 和 `package.json` 放在 Electron 的 `resources/app`，将对应 RID 的自包含 `dotnet publish` 输出放在 `resources/engine`。macOS 对应的目录在 `Electron.app/Contents/Resources`，本地分发按 macOS 要求进行签名。
